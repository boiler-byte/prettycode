Füge Code ein, öffne eine Datei oder ziehe sie in die Eingabe. Das Ergebnis aktualisiert sich nach einer kurzen Schreibpause. Deine Eingabe bleibt dabei unverändert.

    
Minify
Der Schalter ist beim Öffnen ausgeschaltet. Eingeschaltet wird jeder Formatierungsvorgang zur Minifizierung, auch bei Dateiimport und Live-Eingabe. Notwendige Leerzeichen und Einrückungen bleiben erhalten; Bezeichner werden nicht umbenannt.
Automatische Erkennung
Dateiendungen und typische Sprachmerkmale helfen bei der Auswahl. Bei kurzen oder mehrdeutigen Ausschnitten kannst du die Sprache selbst festlegen.
Fehleranzeige
Parserfehler werden mit Zeile und Spalte angezeigt, sofern der Parser eine Position liefert. Die Formatierung ist keine vollständige Codeanalyse. MySQL erhält eine Formatierungsprüfung, keine Datenbankvalidierung. DELIMITER und Stored Procedures werden nicht unterstützt.
Python
Der Python-Formatter Black lädt beim ersten Einsatz eine zusätzliche Browser-Laufzeit. Das kann einen Moment dauern. Im normalen Formatierungsmodus verwendet Black vier Leerzeichen; die Einrückungseinstellung gilt hier nicht. Minify entfernt überflüssigen Leerraum und behält notwendige Python-Einrückungen bei. Dein Python-Code wird nicht ausgeführt.
XML
Wohlgeformtheitsprüfung mit Tag-Verschachtelung, Attribut-Syntax und Entitätsreferenzen; keine Schema-Validierung (DTD/XSD). Die Formatierung richtet Elementinhalte ein und lässt Textinhalte sowie gemischte Inhalte unverändert. Minify entfernt nur überflüssige Einrückung zwischen Elementen – Kommentare, CDATA und Text bleiben erhalten.
Installation & Offline
prettycode. lässt sich in unterstützten Browsern als App installieren. Öffne die Formatierungsoptionen (Schieberegler) und wähle „Offline vorbereiten“, solange du online bist. Damit werden die Bibliotheken für HTML, CSS, JavaScript, MySQL, PHP, JSON und XML sowie Syntaxfarben lokal zwischengespeichert. Die große Python-/Black-Laufzeit und ihre Python-Pakete müssen zunächst online geladen werden und sind offline nicht in jedem Browser zuverlässig verfügbar. Deine Eingaben werden nicht im Cache gespeichert. Installation und Offline-Modus erfordern HTTPS oder localhost.
Browser & Datenschutz
Dein Code wird lokal verarbeitet und nicht an einen Formatierungsserver gesendet. Externe Bibliotheken werden bei Bedarf über CDN geladen; dafür ist Internet nötig. Es werden keine Codeeingaben dauerhaft gespeichert. Dateien bis 1 MiB werden unterstützt.
